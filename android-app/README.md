# تطبيق تقدّم لأندرويد

هذه أول شريحة عملية من التطبيق الأصلي، مكتوبة بـ Java وواجهات XML فقط.

## الموجود الآن

- هوية بصرية عربية ودعم RTL.
- Navigation Component للتنقل بين قائمة المواد ونموذج الإضافة/التعديل.
- RecyclerView يعرض المواد وحالة فارغة واضحة.
- View Binding بدل البحث اليدوي عن عناصر الواجهة.
- ViewModel وLiveData لربط الواجهة بالبيانات مع احترام دورة حياة الشاشة.
- Room بثلاثة جداول أولية: الأهداف، المواد، والجلسات الدراسية.
- Repository يفصل الوصول إلى البيانات عن الشاشات.
- تحقق من اسم المادة والهدف الأسبوعي، مع اختبارات JUnit لهذا المنطق.
- حفظ محلي يعمل دون إنترنت ويستمر بعد إغلاق التطبيق.

## التشغيل

1. افتح مجلد `android-app` من Android Studio.
2. اسمح للبرنامج بتنزيل Android SDK 35 وGradle عند أول مزامنة.
3. شغّل التطبيق على محاكي أو هاتف يعمل بنظام Android 7.0 أو أحدث.
4. لتشغيل الاختبارات اختر `app` ثم شغّل اختبارات الوحدة، أو استخدم مهمة `testDebugUnitTest` من نافذة Gradle.

> لا يحتوي هذا الجهاز حاليًا على Android SDK أو Gradle Wrapper، لذلك يلزم إكمال تنزيل أدوات Android Studio قبل تنفيذ البناء محليًا.

## بنية Java المختصرة

- `data/`: جداول Room وDAO وRepository.
- `ui/subjects/`: الشاشات، ViewModel، ومحوّل RecyclerView.
- `MainActivity`: حاوية التنقل فقط؛ لا تحتوي على منطق الأعمال.

## المرحلة التالية

إضافة DAO للجلسات، تسجيل جلسة يدويًا، حساب التقدم الأسبوعي بالنسبة إلى هدف كل مادة، ثم شاشة التفاصيل والمؤقت.
